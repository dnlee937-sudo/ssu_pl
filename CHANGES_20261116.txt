1. 바꾼 내용
(1) 사전식 목적 (식 [1], [9])
    - 내부 주차장의 초과 대기 면수 E_b를 항상 허용하고(벌점 1,000만 원 방식 삭제), 외부 주차장은 용량을 넘지 못하게 했다.
    - 초과 대기량 F = 5분 x 블록 길이 x E_b 의 합. model.py: excess(), F(), Z(), normalize(), set_stage().
    - 1단계: F 최소화.  2단계: F <= F* 행을 걸고 총비용 Z 최소화.  simulate.py: replan().
    - 1단계 시간 상한은 재계획 시작 후 40초(stage1_limit), 초과 대기가 0이면 1단계를 건너뛴다.
(2) 기술자의 차량 이동 참여 (식 [14])
    - 직원 운행마다 자격군별 참여 인원 변수(cw)를 두었다. 일반직원 사용량 = 필요 인원 - 기술자 참여 인원.
    - 규칙 기반 구성은 일반직원 -> 기술자 -> 탁송 순으로 고른다. 검산기도 자격군별로 인원을 센다.
(3) 이월 작업 평가액 (C2)
    - 작업당 균등 분담 최솟값 대신, 남은 작업의 최소 직접비 V_ik 의 차분으로 계산한다.
(4) 완료 평가 시점 (식 [15] 마지막 항)
    - 계획 종료를 넘겨 끝나는 신규 대안의 초과분을 지연과 보유비에 반영했다.
(5) 계획기간

(6) 종료 상태
    - 초과 대기가 남아도 검산을 통과하면 실행하고 초과 대기량을 기록한다. '유효 계획 미확보' 중단은 없앴다.
(7) LNS
    - 1단계 연산자: 무작위 / 초과 대기 블록 차량 / 연관 / 동일 운송.  2단계: 무작위 / 비용 / 연관 / 동일 운송.
    - 수용: 1단계는 F가 줄 때, 2단계는 (F, Z) 사전식으로 좋아질 때. 계획 검산 통과가 조건.
(8) 정책

    - lnsc_m1: 이전 계획을 이어받는 선택 변형(stage C). 시험 실행에서 효과가 없어 기본 정책에서 제외했다.

(9) 근무시간을 넘는 내부 작업의 다음 영업일 이어하기 (제3장 가정 (2), p_ijt)
    - 내부 작업은 근무시간 안의 어느 후보에서나 시작할 수 있고, 18:00에 멈춘 뒤 다음 영업일 09:00에 이어진다.
      예: 17:30에 시작한 60분 작업은 다음 영업일 09:30에 끝난다.
