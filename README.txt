제3장 실행 코드 수정본 — 2026-11-10

기존 MILP와 LNS 구조를 유지하고 확인된 두 오류 및 단가 입력을 수정했다.
품질·재작업 확률, 반복 공정, 새 해법은 추가하지 않았다.

1. 수정 내용

잔여시간: 묶음 작업을 포함하는 작업별 최소시간을 합하던 계산을 논문에 정의된
최소 잔여경로 시간의 차분으로 바꿨다. 목적함수의 보유비용, 지연 제약, 해 인코딩,
초기 일정의 잔여시간 판단에 함께 적용했다. 기존 반례의 45분이 35분으로 수정됐다.

날짜 경계: 10·15분 주차 블록이 자정을 넘으면 그 블록이 포함하는 모든 날짜에
필요한 임차면을 확보하도록 했다. 초기 일정의 일별 임차량과 위반량 계산도 맞췄다.
23:55~00:05 외부 대기 1대, 외부 기본면 0, 일별 임차료 25인 검증 사례에서
5·10·15분 모두 양일 1면씩 확보하고 목적값 50, 독립 검산 통과를 확인했다.

단가: 소·중작업의 기본 외주비를 내부와 같게 두었다. 대작업은 내부가 저렴한
관계를 유지한다. 아래 금액은 모두 합성 검증 입력이며 실제 견적이 아니다.

동일 작업 범위                내부        외주(왕복 탁송 포함)
세차                          45,000      45,000
일반 정비                     45,000      45,000
전기 작업                     65,000      65,000
엔진 작업                     240,000     480,000
소·중작업 판금+도장            150,000     150,000
대작업 판금+도장               300,000     360,000

최종검수 15,000원은 내부·외주 경로 모두에 공통이다. 대작업 외주 360,000원은
내부 대비 20% 할증을 둔 임시 실험값이다. 실제 견적이 있으면 그 값으로 교체한다.

2. 가격을 조절하는 위치

instance.py의 기존 CAT 표에서 O=(비용, 시간, 공급자)의 첫 숫자를 수정한다.
판금·도장 묶음은 BUNDLES 표의 첫 숫자를 수정한다. 변수나 제약을 추가할 필요가 없다.
예를 들어 일반 정비 외주비를 45,000원에서 42,750원으로 바꾸면 내부 대비 5% 낮은
가격 조건이 된다. 소·중작업의 외주비가 같거나 낮은 입력을 허용한다.
대작업(엔진, 대작업 판금·도장)은 내부 합계보다 외주비가 높아야 하는 기준을 검사한다.
외주 견적에 포함된 왕복 탁송료를 다른 운송비 항에 다시 더하지 않는다.

가격을 바꾼 이후의 일정과 목적값은 다시 계산해야 한다. 과거 결과 파일의 가격만
고쳐 새로운 최적화 결과로 사용하면 안 된다. 이번 기본 단가에는 재작업 기대비용이
포함되어 있지 않으며, 싼 외주가 품질이 낮다고 가정하지 않았다.

3. 재현

검증한 환경은 Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0이다.
이 폴더에서 다음을 실행한다.

python3 -m pip install -r requirements_validation.txt
python3 verify_all.py

검증 실행기는 설치된 highspy를 사용하거나, 없으면 이 검증 환경에서 확인한
SciPy 내장 HiGHS 엔진을 연결한다. 원래 실행 코드의 highspy 연결은 유지했다.
기존 본실험용 실행 파일의 의존성은 requirements.txt에 별도로 남겨 두었다.

validation/verification_results.json: 수식 대조, 두 오류 회귀, 오류 주입, 롤링 실행 결과.
validation/verification_run.log: 이번 실제 실행 로그.
validation_cost/cost_validation.json 및 cost_table.csv: 단가 검증과 실제 선택 결과.
verify_all.py 및 verification_cases.py: 검증용 코드. 운영 모형의 의사결정은 추가하지 않는다.

4. 검증 결과

수식 대조 45회 전부 일치(양쪽 최적 39회, 양쪽 불가능 6회).
독립 계산으로 목적값을 확인하고 서로의 해를 대입해 제약·정수성을 확인했다.
의도한 위반 13개 탐지. 날짜 경계·진행 중 외부 주차 15개 사례 통과.
5·10·15분별 3대·2일 롤링 실행 3회 모두 검산 통과. 각 실행은 재계획 2회,
작업 시작 3건, 이동 1건, 인도 3건이며 LNS 개선 시도 6회가 실행됐다.
기존 회귀 스크립트 3개 통과(상태 인계 스크립트는 단위검사 5개).
차량 600대에서 외주 대안 738개를 확인했다. 대작업은 내부비보다 높고,
소·중작업은 기본값이 같은 가격이다. 5% 저렴한 입력을 허용하는 것도 확인했다.
대작업은 내부 자원이 충분하면 내부 경로 315,000원, 내부 인력이 없으면
외주 경로 375,000원을 선택하며 두 일정 모두 검산을 통과했다.

두 모형은 시작 후보와 열 배치를 공유한다. 검증은 모든 입력의 무오류 증명이 아니며
대규모 성능 실험도 아니다. 14일·4주 전체 실험은 재실행하지 않았다.
기존 HWP·PDF 및 과거 실험 수치는 수정하지 않았다. 변경한 단가와 코드로 논문의
성능 결과를 갱신하려면 전체 비교 실험을 다시 수행해야 한다.
